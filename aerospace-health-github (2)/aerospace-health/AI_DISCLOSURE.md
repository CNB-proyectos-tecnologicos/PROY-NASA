# AI assistance disclosure

The source code in this repository was developed with the assistance of generative AI tools, including Anthropic's Claude,
under human direction. This covers the web interface (`web/`, `web_src/`), the HTTP server (`servidor.py`), the build and
translation scripts, and the documentation, and may also apply to other parts of the project.

What this means for anyone using or reading the code:

- AI-generated code can contain errors, omissions or insecure patterns. Review it before relying on it.
- The clinical rules, thresholds, medical terms and reference ranges have **not** been clinically validated.
- The machine-learning ensemble was trained and evaluated on **synthetic data only**. Its scores are triage-level scores,
  not probabilities of disease.
- Replies from the language model (the "Astronaut Healer" assistant) are generated text and can be wrong.
- This is a research prototype. It is **not a medical device**, it is not certified for flight or clinical use, and it must
  not be used to diagnose, treat or make any real medical decision.
