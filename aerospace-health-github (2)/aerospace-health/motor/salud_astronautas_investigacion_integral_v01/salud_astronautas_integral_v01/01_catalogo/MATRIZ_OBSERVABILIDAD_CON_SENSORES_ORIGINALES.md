# ¿Qué enfermedades espaciales son observables con el conjunto de sensores exigido?

**Conjunto base:** edad, talla, masa, T corporal, etnicidad autodeclarada, fase del ciclo cuando aplique, antropometría, HR continuo, BP continuo **validado**, CGM, SpO₂. No se presupone ECG, ECG-Holter, Doppler, OCT, DXA, laboratorio, actigrafía, acelerómetro, sensores ambientales, entrevista sintomática ni tratamientos.

| Condición / problema | Detección con BASE | Patrón posible (base) | ¿Qué dato adicional es decisivo? | Riesgo individual porcentual disponible | Límite causal |
|---|---|---|---|---|---|
| Hipoxemia | Cribado condicionado | SpO₂ baja persistente | Gasometría/SpO₂ validada, ambient O₂ | No | Sensor / perfusión |
| Deterioro circulatorio | Señal fisiológica | PA baja + FC alterada | Evaluación clínica, perfusión, ECG | No | Etiología múltiple |
| Hipertensión | Si PA validada y protocolo | Media PAS/PAD persistente | PA clínica apropiada, contexto | No | Cuffless no validado |
| Hipoglucemia intersticial | Sí, en seguimiento | CGM<70; CGM<54 | Glucosa capilar/plasmática si discordancia | No | CGM no diagnostica diabetes |
| Diabetes no conocida | Riesgo, NO diagnóstico | Glucosa intersticial elevada repetida | Plasma venoso/HbA1c | No | Diagnóstico analítico |
| Estrés térmico | Señal | Temp central alta + HR | Fuente calor, estado hidratación, examen | No | Causas múltiples |
| Arritmia/FA | NO confirmable con PPG | Pulso irregular estimado | ECG interpretado | No | PPG no identifica FA con certeza |
| Isquemia miocárdica | No | FC/PA quizá normales | Síntomas, ECG, troponina | No | No descartar desde biometría |
| Trombo yugular espacial | NO | Puede ser asintomático | Doppler yugular | No | No inferir por HR/SpO₂ |
| TEV sistémica | No | HR alta inespecífica | Clínica/imágenes/dímero D | No | Score no es probabilidad |
| SANS | NO | Cambios presión/visión no medibles | OCT, fondo de ojo, refracción | No | Requiere neuro-oftalmología |
| Pérdida densidad ósea | NO | Masa normal posible | DXA longitudinal | No | No inferir de peso |
| Pérdida fuerza EVA | NO | Masa/HR cambios sugestivos | Dinamometría/pruebas de ejercicio | No | No inferir de masa |
| Reducción VO₂max | NO exacta | FC ejercicio si carga conocida (no obligatoria) | CPET o prueba indirecta validada | No | Protocolo EVA específico |
| Litiasis renal | NO | Ninguna señal específica | Ecografía, solutos, orina | No | Puede ser asintomática |
| Función renal deteriorada | NO | PA/cambios fluidos inespecíficos | Creatinina/eGFR/ACR | KFRE sólo con labs y ERC G3-G5 | No transferir KFRE a astronautas en vuelo |
| Anemia espacial | NO | FC elevada inespecífica | Hb, reticulocitos, marcadores hemólisis | No | 54% hemólisis no es anemia 54% |
| Neutropenia | NO | Temp fiebre posible | Biometría hemática diferencial | No | Fiebre no identifica ANC |
| Infección/sepsis | Alerta sindrómica no diagnóstica | Temp/FC/PA/SpO₂ | Síntomas, cultivos, examen, labs | No | Diferencial amplio |
| Disfunción tiroidea | NO | FC/temp cambios | TSH, T4L | No | No diferenciar por FC sola |
| Alteración ovulatoria | NO | Fase declarada no confirma ovulación | Perfil hormonal validado | No | Supresión hormonal |
| Ingesta insuficiente | NO concluyente | Pérdida masa | Dieta registrada, balance energético | No | Desplazamiento fluido |
| Deshidratación | Señal inespecífica | FC/PA/temp y masa | Ingesta y diuresis, electrolitos | No | Microgravedad altera fluidos |
| Sueño insuficiente | NO exacto | FC circadiana | Actigrafía/diario/PVT | No | HR no mide sueño fiable |
| Deterioro neurocognitivo | NO | Ninguno específico | PVT, batería cognitiva y entrevista | No | No inferir psiquiatría por HRV |
| Síndrome de descompresión EVA | NO diagnóstico | Cambios cardiorrespiratorios posibles | Perfil presión, tiempo prebreathe, examen | No | Requiere protocolo EVA |
| Hipoxia de cabina | NO ambiental | SpO₂ puede alterarse tarde | Presión total, FiO₂, PIO₂ | No | SpO₂ no reemplaza ECLSS |
| Hipercapnia de cabina | NO ambiental | Cefalea no medida, HR variable | Sensor ppCO₂ 1 hora | No | No inferir PPco₂ de HR |
| Radiación aguda/crónica | NO | Ninguno fiable predaño | Dosímetros, espectro, tasa | REID sólo modelo validado especializado | No usar 600 mSv como P=3% individuo |
| Hipoacusia | NO | No detectable | Audiometría, dosimetría dBA | No | Ruido fuera set base |
| Disfunción vestibular retorno | NO | No sin evaluación movimiento/equilibrio | Tests sensorimotores y marcha | No | Cambios postgravedad |
| Cambios psiquiátricos | NO | HRV no específica | Evaluación confidencial profesional | No | Evitar vigilancia laboral encubierta |

**Interpretación práctica**: el sistema básico actúa como **centinela fisiológico general**, no laboratorio neuro-oftálmico, radiológico ni ergométrico. Para medicina espacial de verdad, el conjunto más valioso de ampliaciones es telemetría del vehículo, dosimetría individual, actigrafía/PVT, OCT, Doppler yugular, DXA, pruebas de fuerza/CPET, orina y paneles sanguíneos seleccionados.
